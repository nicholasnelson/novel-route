Shared visits: "last seen" for every library

When you mark a visit, the app later tells our server "this library was seen on this date": no account, no ID, nothing about you. The server keeps one last-seen date and a monthly count per library. Everyone then sees when a library was last seen, which helps with libraries that may have gone, and later lets us show popular ones.

1. Told once, at your first visit

Shows after your first visit is marked (after the doors hint). Nothing is sent until it's been seen. "Don't share" turns it off; either way it doesn't show again.

Help others find libraries

When you mark a visit (or that you couldn't find a library), Novel Route later tells our server, so others know it's still there. Nothing about you is sent or kept. You can turn this off in My visits.

How it works (not visible)

What's sentLibrary ID and the visit's date (no time), in the request body. Visits marked for today or the last 7 days; older past visits aren't sent. Undone or deleted before sending: dropped.
WhenAt least an hour after the visit, the next time the app is open, one request per visit (so the time you were there isn't sent, and visits aren't bundled together).
Server keepsPer library and month: a count and the latest date seen. No IP, no device, no list of reports. Rate-limited per IP; dates outside the last week and unknown libraries are rejected.
App getsGET /v1/sightings: last-seen date for every library seen in the past year, checked daily with the snapshot (separate, so the snapshot isn't re-downloaded every day).
Couldn't find itSame request with kind: "missing". Server keeps the latest "missing" date per library. Shown as "Someone couldn't find it" only while it's newer than the last sighting. Not sent to Street Library yet: a weekly list for Street Library can come later (with the reporting decision on the held branch).
Popular librariesThe monthly counts are stored from day one; how to show them (a "Popular" tag, sorting in Nearby) is for later. Counts are rough: one person visiting often counts each time.
