Door timings, finish at the last library, and clusters

Three changes from a tester's feedback (2026-11-10). Orange dashes mark what's new.

1. Make the door timings easier to find

Today the timings are only in the map key (••• → ?). The one-off hint after your first visit still says the doors close "over the months", which has been wrong since doors went to a week and a month.

1a. The hint after your first visit

New wording with the actual timings. It shows once, like now.

The doors are open

Marking a visit opens a library's doors. They stay wide open for a week, half open for a month, then just ajar: a reminder there might be new books to find.

3. Clusters show how many you've visited, and group only when markers would overlap

Today a cluster's ring is all amber if any library in it is unvisited, otherwise green. The new ring is split: green for the share you've visited, amber for the rest, so a fully explored suburb reads as a green ring even zoomed out.

3a. Before and after

The ring is drawn in eighths (green rounds down, so a ring is only all green when every library is visited). The ring sizes and count stay as they are.
