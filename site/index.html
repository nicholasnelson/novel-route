About

Novel Route is a small independent project built by a street library fan. It's free, and the source code is on GitHub.

Library locations come from Street Library Australia. If you look after a street library that isn't on the map, register it with them.

Novel Route is not affiliated with, endorsed by, or associated with Street Library Australia.
